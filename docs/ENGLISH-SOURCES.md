# Web of Science 检索与全文

英文主流程使用 Web of Science Core Collection。学校访问路线为北外 WebVPN → 图书馆资源 → WoS；门户、数据库页面与出版商全文在机构浏览器会话中连续访问。适配涉及全球站及中国区域站，保留学校网关改写后的 URL。

## 检索记录

`comm_wos_search` 接收 1–6 个显式主题表达式，支持布尔运算和带引号的短语。服务添加 `TS`、年份和英文语言条件，在可见网页中提交检索，再通过页面的 Full Record 导出获得书目。每个表达式最多导出 100 条，结果按研究问题合并排序。

Full Record 解析保留完整作者、DOI、摘要、期刊、年份、卷期页码、入藏号及可得的索引信息。WoS 书目作为来源记录用于后续下载和导入，不通过其他检索源替换。结果覆盖范围受学校订阅、检索条件和导出上限约束。

## 全文获取

服务打开选定记录，沿页面的出版商或 SFX 全文入口进入目标页面，再识别 PDF 链接、元信息或下载按钮。文件响应在已认证浏览器中捕获，保留文件后进行首页 DOI / 标题核验。只有核验通过的回执才包含可作为已验证附件使用的 `pdf_path`。

| 状态或信号 | 含义与处理 |
| --- | --- |
| `downloaded` | PDF 已通过身份核验 |
| `identity_unverified` | 文件已保留，身份依据不足，需人工核对 |
| `authentication_required` / `needs_attention` | 在浏览器完成登录或验证码，再重试 |
| `no_library_fulltext` | 图书馆解析服务未提供可用全文 |
| `running` | 请求仍在执行，相同 WoS 请求重试会等待原任务 |

WoS 订阅不直接赋予所有出版商全文权限。开放获取 PDF 可以不依赖个人登录；需机构订阅的全文必须保留对应的机构访问上下文。网页结构、出版商限制和不完整文件响应也会造成下载失败，工具会保留诊断而不把落地页当作 PDF。

## 模块关系

- `comm_wos.py`：查询合并、候选排序与经过核验的下载回执。
- `comm_wos_host.py`：学校入口、WoS 页面交互、Full Record 解析、全文跳转及文件捕获。
- `comm_cnki.py`：同一服务内串行执行浏览器任务，避免多个请求争用页面。
- `cnki/browser.py`：浏览器生命周期与北外网关会话持久化。

CNKI 使用北外 WebVPN 时与 WoS 共享机构浏览器；CNKI 配置为直连时，WoS 使用独立的 WebVPN 浏览器。网关 cookie 加密保存，出版商会话还可能需要在当前浏览器中重新建立。

## 可选通用来源

上游来源类、通用检索与开放获取适配器保留在代码中。主服务默认不注册这些兼容工具；设置 `COMM_ENABLE_LEGACY_TOOLS=1` 后可调用 `comm_search`、`comm_search_many` 及兼容入口。兼容工具具备各自的网络、API key 和来源限制，不能据此推定 WoS 路线可访问某个全文。IEEE / ACM 占位适配器不提供实际检索能力。
